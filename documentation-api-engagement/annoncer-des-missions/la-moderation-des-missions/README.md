# Modération des missions partagées

Les missions reçues par l'API Engagement sont soumises à une (double) modération :&#x20;

* Une première modération effectuée par l'API Engagement elle-même. [En savoir plus](moderation-api-engagement.md).
* Une seconde modération par les partenaires diffuseurs de l'API Engagement (notamment jeveuxaider.gouv.fr). [En savoir plus](moderation-des-partenaires-diffuseur.md).
