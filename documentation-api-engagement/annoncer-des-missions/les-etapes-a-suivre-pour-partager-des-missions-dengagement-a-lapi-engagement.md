# Les étapes à suivre pour partager des missions d'engagement à l'API Engagement

*   **Étape 0** : **Devenir partenaire de l'API Engagement**

    Contactez l'équipe de l'API Engagement via [cette page](https://api-engagement.beta.gouv.fr/#contact).



* **Étape 1 : Mettre ses missions à disposition de l'API Engagement** \
  Deux options :
  * via un flux XML (cf. Méthode 1 : [Création d'un flux XML](creation-dun-flux-xml/methode-1-creation-dun-flux-xml/)) ;
  * via l'API (cf. Méthode 2 : [Création de missions par API](creation-dun-flux-xml/methode-2-creation-de-missions-par-api.md))



*   **Étape 2 : Mettre en place le suivi des candidatures**

    Deux cas de figure selon votre dispositif :

    * Cas n°1 : [Votre site internet recueille lui-même les candidatures](tracking-des-candidatures/cas-n-1-votre-site-internet-recueille-lui-meme-les-candidatures/) (formulaire ou parcours utilisateur avec création de compte) : ajoutez le script de suivi des candidatures sur votre site.
    * Cas n°2 : [Votre site internet ne permet pas de recueillir les candidatures](tracking-des-candidatures/cas-n-2-votre-site-internet-ne-permet-pas-de-recueillir-les-candidatures.md) (pas de formulaire ni de parcours d'inscription) : utilisez la connexion avec Démarches Numériques pour créer un formulaire d'inscription ; les candidatures seront trackées via cette connexion.

\
À l'issue de l'étape 2, vos missions peuvent être diffusées auprès du réseau de 300+ diffuseurs de l'API Engagement. Les bénévoles et volontaires seront alors redirigés sur votre site pour effectuer leur candidature.
