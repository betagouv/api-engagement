# Étape 2 : mettre en place le suivi des candidatures

Si vous recevez du trafic de l'API Engagement, vous devez nous **transmettre les informations** des candidatures générées et des comptes créés (inscriptions). Deux cas de figure selon votre dispositif :

## [Cas n°1](cas-n-1-votre-site-internet-recueille-lui-meme-les-candidatures/) : Votre site internet recueille lui-même les candidatures **(**&#x66;ormulaire ou parcours utilisateur avec création de compte)

Ajoutez le script de suivi des candidatures sur votre site. Vous avez **deux options** pour le faire :

* 1\. [En utilisant une balise sur votre site en en déclenchant des commandes](cas-n-1-votre-site-internet-recueille-lui-meme-les-candidatures/installer-le-tag-api-engagement-methode-recommandee.md) _- Implémentation simple et conseillée_
* 2\. [En effectuant un appel à l'API ](cas-n-1-votre-site-internet-recueille-lui-meme-les-candidatures/tracking-de-lactivite-par-api-implementation-manuelle.md)- _Implémentation manuelle_



## [Cas n°2](cas-n-2-votre-site-internet-ne-permet-pas-de-recueillir-les-candidatures.md) : Votre site internet ne permet pas de recueillir les candidatures (pas de formulaire ni de parcours d'inscription)

Utilisez la connexion avec demarche.numerique.gouv.fr pour créer un formulaire d'inscription ; les candidatures seront trackées via cette connexion.
