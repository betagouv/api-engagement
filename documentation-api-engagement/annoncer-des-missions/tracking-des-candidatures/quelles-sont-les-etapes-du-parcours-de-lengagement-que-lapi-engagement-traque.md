# Quelles sont les étapes du parcours de l'engagement que l'API Engagement traque ?

Sur la partie droite, dans le cadre vert (Site Annonceur A), l'API traque plusieurs étapes du parcours de l'engagement grâce à l'exécution de commandes sur le site de l'annonceur (vous). L'API peut ainsi donner des statistiques consolidées à ses partenaires :

* **sur le nombre de candidatures pour une mission donnée**. Cette candidature peut soit venir (1) d'une diffusion "directe" de la mission sur un site diffuseur ou (2) d'une diffusion "indirecte" via une campagne (ou lien tracké) suite à une campagne email
* **sur le nombre d'inscriptions (ou de création de comptes) sur le site annonceur** (en précisant de quelle mission provient cette inscription)
