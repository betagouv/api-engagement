# Partager les données de diffusion sur mon site à l'API Engagement

{% hint style="danger" %}
Cette section ne s'adresse qu'aux **diffuseurs ayant choisi l'intégration par API et/ou par lien tracké**.
{% endhint %}

## Introduction : étapes du parcours de l'engagement trackés par l'API

* Sur la partie gauche, dans le cadre bleu (Site diffuseur B, vous), &#x6C;**'API traque les impressions**.
* Sur la partie droite, dans le cadre vert (Site annonceur A), l'API traque plusieurs étapes du parcours de l'engagement. L'API peut ainsi donner des statistiques consolidées à ses partenaires :
  * **sur le nombre de candidatures pour une mission donnée**.&#x20;
  * **sur le nombre d'inscriptions (ou de création de comptes) sur le site annonceur**

## Les données à partager en tant que diffuseur à l'API Engagement

{% hint style="warning" %}
L'API Engagement recueille obligatoirement les données de diffusion suivantes de la part de ses partenaires diffuseurs.
{% endhint %}

### Pourquoi partager des données de diffusion à l'API Engagement ?&#x20;

* L'API Engagement met à disposition un stock de missions d'engagement à ses partenaires diffuseurs. En contrepartie, celle-ci demande de renvoyer l'information des informations de missions non diffusées ou diffusées ' dans le stock mis à disposition et les raisons de cette non diffusion.
* L'API Engagement permet à ses partenaires annonceurs d'accéder à des statistiques de diffusion. Pour effectuer un rapport complet sur les statistiques de diffusion

### Quelles sont les données à partager à l'API Engagement en tant que diffuseur ?

* Les [données de missions non diffusées par le partenaire diffuseur](missions-non-diffusees-sur-mon-site.md) (concerne uniquement les diffuseurs ayant choisi l'intégration API) : le diffuseur doit partager les données de missions qu'il ne diffusent pas et la raison.
* Les [données d'impressions (vues)](partager-vos-statistiques-de-diffusions-impressions-a-lapi-engagement/) pour les missions diffusées ou les liens de campagnes dits "trackés".
