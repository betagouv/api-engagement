# Diffuser des missions d'engagement sur mon site

## Plusieurs méthodes pour diffuser des missions d'engagement

Il existe trois méthodes pour diffuser plus de 40 000 missions de bénévolat et de volontariat. Cela peut se faire :

* [Par API](diffuser-des-missions-par-api.md)
* [Via le widget](diffuser-des-missions-par-widget.md)
* [Via des campagnes avec des liens dits "trackés" ](diffuser-des-missions-par-lien-tracke.md)

## Quelle méthode d'intégration choisir ?

Les solutions de diffusion ont été développées pour répondre aux besoins de tous, que le diffuseur dispose de compétences techniques avancées ou non, d'un temps limité pour l'intégration ou d'un besoin de personnalisation du parcours utilisateur.

| Type d'intégration recommandée                                        | Contexte diffuseur                                                                                                                                                              | Compatibilité                       |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| [API](diffuser-des-missions-par-api.md)                               | <ul><li>Je dispose de capacité de développement (interne ou externe).</li><li>Besoin du personnalisation du parcours utilisateur et des informations affichées.</li></ul>       | Site / Application mobile           |
| [Widget](diffuser-des-missions-par-widget.md)                         | <ul><li>Je dispose de capacité de développement très limité.</li><li>Je souhaite présenter un catalogue de missions sur mon site.</li></ul>                                     | Site / Application mobile (webview) |
| [Campagnes / Liens Trackés](diffuser-des-missions-par-lien-tracke.md) | <ul><li>Je dispose de capacité de développement très limité.</li><li>Je souhaite renvoyer mes visiteur vers le site annonceur sans présenter de catalogue de mission.</li></ul> | Site / Application mobile           |
