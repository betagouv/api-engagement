# Diffuser des missions par lien tracké

La diffusion des missions de l'API Engagement par ou lien tracké (ou campagne), est la manière la plus simple et rapide d'intégrer l'API Engagement à votre site web.

## Étape 1 : intégrer un lien tracké

* Il suffit simplement d'intégrer le lien tracké généré par les équipes de l'API Engagement **sur votre support (site web, newsletter, QR code, etc).**
* Le lien prend la forme suivante :&#x20;

```
https://api.api-engagement.beta.gouv.fr/r/campaign/65f86ba2073727e7638dd9d8
```

{% hint style="success" %}
_Exemple d'intégration : sur messervicesetudiants, l'utilisateur voit l'image ou le bouton sur votre site._
{% endhint %}
