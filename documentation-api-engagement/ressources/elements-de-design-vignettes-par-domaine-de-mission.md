# Éléments de design "Vignettes" par domaine de mission

L'API Engagement met à disposition une bibliothèque d'images, pouvant être utilisées pour la diffusion de missions d'engagement via API sur votre site.

_<mark style="background-color:blue;">Bibliothèque d'images disponible fin février 2025</mark>_

NB : Dans la bibliothèque, les images sont numérotées de 1 à 8 suivant les domaines de missions. Veillez à faire correspondre les images et leurs thématiques en cas d'utilisation.

1. Éducation
2. Santé
3. Environnement
4. Solidarité et Insertion
5. Sport
6. Mémoire et Citoyenneté
7. Coopération Internationale
8. Culture et Loisirs
